# Contributing

Thanks for considering a contribution to `socratic`. This is a small, single-skill repo.

## Before you start

- **False positive or false negative in the review logic?** Open an issue with the target you ran it against and which of the seven questions produced an answer that was wrong, hedged when it shouldn't have, or missed available evidence. This is the highest-value kind of report here.
- **Proposing an addition to the reference material or method?** Open an issue describing the gap and, if you're proposing a change to the seven questions themselves or their order, explain why the existing set (see `skills/socratic/SKILL.md`) doesn't already cover it. The fixed order is deliberate: later questions are written not to leak optimism into earlier, harder ones.
- **License or copyright holder:** don't change without asking first.

## Making a change

1. Fork and branch from `main`.
2. Keep edits inside `skills/socratic/`.
3. Preserve the evidence-first rule: every answer the skill produces should cite a file, line, commit, or session moment, and any change to the method should keep that property intact.

## Questions

Open an issue. There's no separate chat or forum for this project.
